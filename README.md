# AtCoder Dynamic Programming Contest

## Introduction

This repository contains solutions to the problems from the AtCoder Dynamic Programming (DP) Contest. The problems are designed to test and improve your understanding of various dynamic programming techniques.

## Problems

Below is a list of problems from the contest along with a brief description and a link to each problem statement.

### A - Frog 1

#### Description
Given the heights of stones, find the minimum cost to reach the last stone. You can only jump to the next stone or skip one stone.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_a)

### B - Frog 2

#### Description
Similar to Frog 1, but you can jump up to \( k \) stones ahead.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_b)

### C - Vacation

#### Description
Maximize the happiness over \( N \) days by choosing one of three activities each day, ensuring that no two consecutive days have the same activity.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_c)

### D - Knapsack 1

#### Description
Given a knapsack of capacity \( W \), and \( N \) items each with a weight and a value, determine the maximum value that can fit in the knapsack.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_d)

### E - Knapsack 2

#### Description
Similar to Knapsack 1, but with different constraints.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_e)

### F - LCS

#### Description
Given two strings, find their longest common subsequence (LCS).

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_f)

### G - Longest Path

#### Description
Given a Directed Acyclic Graph (DAG), find the length of the longest path in the graph.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_g)

### H - Grid 1

#### Description
Count the number of ways to reach the bottom-right corner of a grid from the top-left corner, only moving right or down.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_h)

### I - Coins

#### Description
Given \( N \) coins with probabilities of landing heads, find the probability of having more heads than tails.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_i)

### J - Sushi

#### Description
Given \( N \) plates of sushi, each with 0, 1, 2, or 3 pieces, find the expected number of moves to finish all sushi.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_j)

### K - Stones

#### Description
Given a game where two players take turns to remove stones from a pile, find if the first player can force a win given the number of stones and moves they can make.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_k)

### L - Deque

#### Description
Given a deque of numbers, two players take turns to remove a number from either end of the deque, trying to maximize their total. Determine the score difference if both play optimally.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_l)

### M - Candies

#### Description
Given \( N \) children and \( K \) candies, find the number of ways to distribute the candies such that each child gets at least one candy.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_m)

### N - Slimes

#### Description
Given an array of slime sizes, find the minimum cost to combine all slimes into one.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_n)

### O - Matching

#### Description
Given \( N \) people and \( N \) jobs with a compatibility matrix, find the number of ways to assign jobs to people such that each person gets exactly one job they are compatible with.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_o)

### P - Independent Set

#### Description
Given a tree, find the size of the largest independent set.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_p)

### Q - Flowers

#### Description
Given \( N \) flowers, each with a beauty value and a height, find the maximum sum of beauty values you can obtain by picking flowers in a non-decreasing order of height.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_q)

### R - Walk

#### Description
Given a graph with \( N \) vertices and \( M \) edges, find the number of different ways to reach the \( N \)-th vertex from the 1st vertex in exactly \( K \) steps.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_r)

### S - Digit Sum

#### Description
Given two integers \( L \) and \( R \), find the sum of all integers between \( L \) and \( R \) inclusive.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_s)

### T - Permutation

#### Description
Given \( N \) integers, find the number of permutations that are "beautiful". A permutation is beautiful if the greatest common divisor (GCD) of any two consecutive numbers in the permutation is greater than 1.

#### [Problem Statement](https://atcoder.jp/contests/dp/tasks/dp_t)

## Solutions

This section contains the solutions to the problems listed above. Each problem has its own directory with the problem name, containing the solution code and any necessary documentation.
